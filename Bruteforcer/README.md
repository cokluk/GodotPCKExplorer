# PCK Bruteforcer

Finds Godot 4 PCK encryption keys by scanning an executable for the key bytes.

Pre-built downloads: **[cokluk/GodotPCKExplorer releases](https://github.com/cokluk/GodotPCKExplorer/releases/latest)** (look for `PCKBruteforcer_*` assets).

![Screenshot](Images/screenshot_ui.png)

Based on the tool in [DmitriySalnikov/GodotPCKExplorer](https://github.com/DmitriySalnikov/GodotPCKExplorer/tree/master/Bruteforcer).
